# Security policy

This is early software. Security fixes target the latest stable server release
in the 0.2.x series. There is no guaranteed response time, certification or
commitment to backport fixes to older versions.

Do not report exploitable vulnerabilities in public issues. Use
[private vulnerability reporting](https://github.com/ItsAnunesS/elo-talks-server/security/advisories/new)
when enabled. If GitHub reports that private reporting is unavailable, contact
the maintainer privately through the contact details on their
[GitHub profile](https://github.com/ItsAnunesS) before sharing details.

Include the version, affected boundary, impact and a minimal reproduction with
synthetic data. Never submit passwords, session tokens, database URLs, identity
files, TLS private keys or decrypted user content.

See [the threat model](docs/SECURITY.md) for encryption, authorization and trust
boundaries, and [validation evidence](docs/VALIDATION.md) for current limits.
